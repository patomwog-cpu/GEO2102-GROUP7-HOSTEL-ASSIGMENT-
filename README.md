## About
Java program that models hostel records (H28–H31) near campus, showing accommodation type, rental price, occupancy status, and GPS coordinates. It calculates the average rental price and counts fully vs. not-fully-occupied hostels.

## Files
- `src/Main.java` — entry point, builds the hostel records and prints the report
- `src/Hostel.java` — Hostel class (fields, constructor, getters, `isOccupied()`, `displayDetails()`)
- `program-output.txt` — sample output from running the program
- `Group7_Assignment_Report.docx` — written assignment report

## How to Run
1. Make sure you have Java installed (`java -version`).
2. Open a terminal in the `src` folder.
3. Compile:
   ```
   javac Main.java Hostel.java
   ```
4. Run:
   ```
   java Main
   ```
